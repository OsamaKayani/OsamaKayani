# Osama Rehman Kayani

Mechanical engineer working across **AI engineering, computer vision and humanoid robotics**. I like projects where software has to respect physical constraints: camera timing, actuator limits, kinematics, testability and safety.

## Featured work

### [JobIntel AI](https://github.com/OsamaKayani/python-engineering-automation)
Explainable job-to-evidence matching, honest gap detection and automated interview briefs. The same repository also contains an early **Anerkannt AI** prototype for comparing university modules by outcomes, ECTS and assessment compatibility.

### [Safe Humanoid Robotics Prototype](https://github.com/OsamaKayani/humanoid-robotics-prototyping)
Hardware-independent LLM-to-actuator planning with structured commands, human approval, deterministic joint/velocity limits, emergency stop behavior and simulated M8010/M4215 configuration.

### [PV Thermography Automation](https://github.com/OsamaKayani/pv-thermography-automation)
Portfolio-safe RGB-detection-to-thermal-capture trigger inspired by my Fraunhofer IGP thesis on automated thermographic camera control. Reported thesis evaluation: approximately 92.4% mAP@0.5 on Dataset B.

### [Computer Vision Utilities](https://github.com/OsamaKayani/computer-vision-object-detection)
Inspectable object-detection utilities for bounding-box validation, IoU and non-max suppression.

### [Robot Joint Kinematics](https://github.com/OsamaKayani/robot-joint-kinematics)
Serial-link forward kinematics using Denavit–Hartenberg parameters, backed by numerical tests.

### [Trading Strategy Research](https://github.com/OsamaKayani/trading-strategies)
Auditable structure-break and VWAP research code with explicit assumptions and no unsupported profitability claims.
